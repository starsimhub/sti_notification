# Figures

Deck slide PNGs at the top level; archived + supplementary figures in
subfolders.

## Layout

| Path | Purpose |
|---|---|
| `figures/fig_slide{3,4,5,6,9-12}.png` | Deck slides. Regenerated by scripts in [`../plotting/`](../plotting/README.md). Superseded slide PNGs live in `figures/archive/`. |
| `figures/fig_cascades_4panel_soc.png` | Deck Slide 1. Produced by `../exploratory/plot_cascade.py`. |
| `figures/fig1_algos.png` | Manuscript Figure 1: SOC syndromic-management vs POC diagnostic algorithm for VDS. Reused from `stisim_vddx_zim` (no local generating script); referenced in [`../docs/sti_manuscript.md`](../docs/sti_manuscript.md). |
| `figures/archive/` | Superseded figures. Regeneratable from `../exploratory/`. |
| `figures/supplementary/` | Supplementary-materials figures (`fig_epi_overview.png`, `fig_pn_story_grounding.png`). Produced by `../exploratory/plot_epi.py` and `plot_pn_story.py`. |

## Regenerating

Run any script from the repo root:

```bash
conda run -n starsim python plotting/plot_slide6.py
```

Deck scripts write into `figures/`; exploratory scripts write into
`figures/archive/` or `figures/supplementary/`. See the
[plotting-scripts README](../plotting/README.md) for the full slide →
script → data map, and the top-level
[Regenerating results and figures](../README.md#regenerating-results-and-figures)
section for the full pipeline (factorial run → aggregation → figures).
